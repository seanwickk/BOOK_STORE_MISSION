Inventory Search

Optional, given code. This page reads the inventory.json your script writes and filters your items as you type, so you can spot-check your results. To open it, run python3 -m http.server in your repo's top folder, then go to http://localhost:8000/tools/search.html. Opening the file directly won't work, because browsers block a local page from reading a local JSON file. Press Control+C in Terminal to stop the server.
